# Sergio

**Washington State CPA building source-bound public-grant systems and agent infrastructure.**

Public money arrives with rules attached, and a rule is only worth anything if someone can check it against the record. Most of my work is turning that check into software: post-award closeout, evidence review, and agent tooling that keeps its own reasoning inspectable.

Three-time AI hackathon award winner. Open-source maintainer and upstream contributor.

## Selected systems

### [GrantBack](https://grantback.vercel.app)

A source-bound obligation compiler. It reads fragmented post-award evidence and assembles a candidate receivable package for an accountant to review.

### [Grant Radar](https://github.com/sergiobuilds/grant-radar-public)

Collects Korean public-funding opportunities from multiple sources and exposes them through search and MCP tools.

### [Business Health Check](https://github.com/sergiobuilds/biz-health-check)

Cross-checks official Korean datasets for business status, pension records, sanctions, and corporate facts, without adding interpretation the data does not support.

Smaller agent tools: [Tensei Slime](https://github.com/sergiobuilds/tensei-slime) keeps coding agents coherent across a project, [RightSeat](https://github.com/sergiobuilds/rightseat) puts a visible operator beside terminal AI workers, and [UX Workflow Check](https://github.com/sergiobuilds/ux-workflow-check) finds the user need a specification failed to write down.
